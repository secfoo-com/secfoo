# @rakfortltd/secfoo

AI security review CLI: SAST, secret scanning, SCA, threat modeling and
architecture review, as a standalone binary distributed via npm's
`optionalDependencies` pattern (no Python required).

```bash
npm install -g @rakfortltd/secfoo
secfoo run --skill security-architecture-review --agent claude
```

Full documentation: https://github.com/secfoo-com/secfoo
