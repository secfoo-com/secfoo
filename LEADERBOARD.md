## How points work

Points come from the `difficulty:` label on the issue a merged PR closes (link it with `Fixes #123` in the PR description or the sidebar).

| Issue label | Points |
|---|---:|
| `difficulty: hard` | 10 |
| `difficulty: medium` | 6 |
| `difficulty: low` | 3 |

| Level | Points needed |
|---|---:|
| Level 1 | 100 |
| Level 2 | 50 |
| Level 3 | 25 |

Each issue is scored once, for the first PR merged that closes it. Bots are excluded. Full rules: [CONTRIBUTING.md](https://github.com/secfoo-com/secfoo/blob/main/CONTRIBUTING.md#hackathon-points).
